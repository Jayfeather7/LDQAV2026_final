# LDQAV2026_final
The project is devoted to the speech verbs in the novel 'Crime and Punishment' by F. M. Dostoevsky
/iniquit is the main folder with all results, visualisations, etc. Two main executables are inquit_gender2.py and speech_who.py (start through the terminal). The tagged text resides at the parent directory \prestuplenie_i_nakazanie.xml
